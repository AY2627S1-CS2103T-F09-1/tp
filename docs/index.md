**TutorTrack** is a desktop application for private one-to-one tutors managing a roster of 10 to 40 students. Its command-line interface supports fast keyboard-driven work, while its graphical interface keeps student and lesson information easy to scan.

TutorTrack helps tutors:

* maintain a roster containing each student's name, parent or guardian contact details, subject, and current level;
* open a student profile to retrieve lesson context quickly; and
* record timestamped session notes for future lesson preparation.

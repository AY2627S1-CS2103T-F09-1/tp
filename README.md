# TutorTrack

[![CI Status](https://github.com/AY2627S1-CS2103T-F09-1/tp/workflows/Java%20CI/badge.svg)](https://github.com/AY2627S1-CS2103T-F09-1/tp/actions)

**TutorTrack** is a desktop application designed for private one-to-one tutors managing a roster of 10 to 40 students. It combines a fast, CLI-first interface with a responsive GUI, allowing tutors to quickly review past lesson contexts, look up parent contacts, and record session follow-up notes between classes without friction.
